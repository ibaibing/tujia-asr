## tujia-ctc v0.1 — first public release

Syllable-level speech recognition for Tujia (Northern dialect). Emits toneless
syllable shapes with time spans; tones must be filled in downstream from a lexicon.

- `wav2vec2-xlsr-53-espeak-cv-ft` frozen + LayerNorm + 2× BiLSTM(256) + Linear(512→264)
- 264 labels (blank, `<sep>`, 262 shapes); 4,339,976 trainable parameters (17 MB)
- Best epoch 35, validation CER 0.4125
- Held-out syllable recall 80.26% (108 clips); cross-speaker read speech 79.11%; narrowband field recording 48.85%

The encoder is not bundled: run `./fetch_encoder.sh` inside the unpacked archive
(~1.2 GB, Apache-2.0 upstream). On Windows the script does not run — copy the encoder
folder and point `TUJIA_XLSR` at it; the folder name is arbitrary.

### Known limitations

No tone prediction; clear degradation on narrowband audio; short isolated vowels are
unstable; ~2.6 hours from a single source.

See `docs/protocol.md` for the scoring protocol used for every number above. v0.1 is
superseded by v0.2 for anything that needs tones, but remains the reference point for
architecture comparisons.
